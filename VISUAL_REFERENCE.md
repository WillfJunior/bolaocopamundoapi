## 5. Estrutura de Layout (React)

```jsx
<RankingContainer>
  <Header>
    <Title>🏆 RANKING DO BOLÃO</Title>
    <GroupInfo>Grupo: Friends (5 membros)</GroupInfo>
    <UpdateTime>⏰ Atualizado às 14:35:22 | 🔄 Em tempo real</UpdateTime>
  </Header>

  <FilterBar>
    <TabGroup>
      <Tab active>Posição</Tab>
      <Tab>Pontos</Tab>
      <Tab>Acurácia</Tab>
    </TabGroup>
  </FilterBar>

  <RankingTable>
    {ranking.map((entry, idx) => (
      <RankingCard
        key={entry.userId}
        entry={entry}
        isLeader={entry.isLeader}
        isMoving={entry.positionChange !== 0}
        momentaryPoints={entry.momentaryPoints}
      >
        <Position>{entry.position}</Position>
        <UserInfo>
          <Avatar src={entry.userPhotoUrl} />
          <Name>{entry.userName}</Name>
          {entry.isLeader && <LeaderBadge>👑</LeaderBadge>}
        </UserInfo>

        <ScoreDisplay>
          <TotalPoints>{entry.totalPoints}</TotalPoints>
          {entry.momentaryPoints > 0 && (
            <MomentaryPoints>
              +{entry.momentaryPoints} ⚡
            </MomentaryPoints>
          )}
        </ScoreDisplay>

        {entry.positionChange !== 0 && (
          <PositionChange>
            {entry.positionChange > 0 ? '↑' : '↓'}
            {Math.abs(entry.positionChange)} posição(ões)
          </PositionChange>
        )}

        <Stats>
          <Stat>✓ {entry.exactScores}</Stat>
          <Stat>⚠️ {entry.correctOutcomes}</Stat>
          <Stat>✗ {entry.errors}</Stat>
        </Stats>

        <Accuracy>
          Acurácia: {accuracy}%
        </Accuracy>
      </RankingCard>
    ))}
  </RankingTable>

  <GroupStandings>
    <Title>⚽ CLASSIFICAÇÃO DOS GRUPOS</Title>
    {standings.map(group => (
      <GroupTab key={group.groupName}>
        <GroupName>{group.groupName}</GroupName>
        <StandingsTable>
          {/* Tabela com times */}
        </StandingsTable>
      </GroupTab>
    ))}
  </GroupStandings>
</RankingContainer>
```

## 6. Animações CSS

### Entrada em Tempo Real

```css
/* Quando um jogador sobe de posição */
@keyframes moveUp {
  0% {
    transform: translateY(20px);
    opacity: 0;
  }
  100% {
    transform: translateY(0);
    opacity: 1;
  }
}

.entry-moving-up {
  animation: moveUp 0.6s ease-out;
  background: linear-gradient(90deg, #e8f5e9, transparent);
}

/* Destaque de pontos momentâneos */
@keyframes pointsPulse {
  0%, 100% {
    opacity: 1;
    transform: scale(1);
  }
  50% {
    opacity: 0.7;
    transform: scale(1.1);
  }
}

.momentary-points {
  animation: pointsPulse 1s ease-in-out;
  color: #4caf50;
  font-weight: bold;
}

/* Leader piscando */
@keyframes leaderGlow {
  0%, 100% {
    box-shadow: 0 0 0 0 rgba(255, 215, 0, 0.7);
  }
  50% {
    box-shadow: 0 0 0 10px rgba(255, 215, 0, 0);
  }
}

.entry.leader {
  animation: leaderGlow 2s infinite;
}
```

## Notas de Design

1. **Cores principais:** Azul (1976D2), Verde (4CAF50), Amarelo (FFD700), Vermelho (F44336)
2. **Fonte:** Segoe UI, Roboto, ou similar (sans-serif)
3. **Ícones:** Emojis para simplicidade ou FontAwesome
4. **Responsive:** Mobile first, até 1920px em desktop
5. **Animações:** Suaves (0.3-0.6s), sem overdose
6. **Acessibilidade:** Alto contraste, legendas em imagens
7. **Performance:** Lazy load de avatares, virtualization para grandes listas
